---

### Topology-Aware GNNs for 3D Porous Titanium Scaffolds

Developing a computational pipeline for predicting **stress and strain fields in generative 3D porous titanium scaffolds** using topology-aware graph neural networks.

The project combines:

`Procedural Geometry` → `Finite Element Analysis` → `Graph Construction` → `GNN Field Prediction`

Work includes:

- Procedural generation of **triply periodic minimal surface (TPMS)** structures
- Tetrahedral finite-element simulations
- Mapping FEA stress/strain fields onto graph representations
- Automated dataset construction and quality control
- Training and evaluating GNNs with **PyTorch Geometric**
- Node-level prediction of **von Mises stress** and **equivalent strain**

`Graph Neural Networks` · `PyTorch Geometric` · `FEA` · `CalculiX` · `Scientific ML`
